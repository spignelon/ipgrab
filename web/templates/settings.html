Settings

Conceal mode

When enabled, the login page, dashboard title, and site favicon disguise this instance as a self-hosted Nextcloud install. A casual visitor, port scanner, or screenshot of your browser tab won't see "IPGrab" anywhere — the login form still only authenticates your one real admin account exactly as before, and nothing extra is captured about what anyone else types into it.

This is cosmetic disguise only — page title, favicon, and the login screen's look. It does not mimic Nextcloud's real HTTP headers, page markup, or API endpoints, so it won't fool a technically thorough inspection, only a quick glance. The one-time first-run /setup page always shows real IPGrab branding (concealment can only be turned on after that account already exists) — finish setup and enable this before you point a public subdomain or share any links.
